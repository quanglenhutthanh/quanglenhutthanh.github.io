Câu 61

A company extends Copilot in Microsoft Dynamics 365 Customer Service. You need to recommend an automated application lifecycle management (ALM) process so that the Copilot components can be safely developed, tested, and promoted to production. Which two actions should you include in the ALM process? Each correct answer presents part of the solution. NOTE: Each correct selection is worth one point.

  • A. Use Microsoft Power Platform pipelines.
  • B. Store the agent transcripts in source control.
  • C. Rebuild the agents in each environment.
  • D. Include the components in a solution.
  • E. Use an unmanaged solution in production.

✅ Đáp án chính thức: A, D — Use Microsoft Power Platform pipelines. / Include the components in a solution.

Vì sao đúng: Copilot component phải được đưa vào solution để có thể quản lý, export/import và di chuyển giữa các environment.Microsoft Power Platform pipelines tự động hóa deployment qua development, test và production; giúp giảm thao tác thủ công, bảo đảm quy trình triển khai nhất quán.

Vì sao đáp án khác sai: A. Use an unmanaged solution in production: Unmanaged solution phù hợp cho development vì có thể chỉnh sửa trực tiếp. Production nên nhận managed solution để hạn chế thay đổi ngoài kiểm soát.B. Rebuild the agents in each environment: Làm thủ công dễ sai lệch cấu hình và tốn công; không phải ALM chuẩn.E. Store agent transcripts in source control: Transcript là dữ liệu vận hành/lịch sử hội thoại, không phải component nguồn cần version control và triển khai qua environment.

🪄 Câu thần chú: ALM Copilot: đóng gói vào solution → đưa qua môi trường bằng Power Platform pipelines.

Câu 64

A company plans to deploy a Microsoft Foundry agent. You need to recommend an application lifecycle management (ALM) process to ensure that the agent evaluates against baseline accuracy metrics before being deployed. What should you recommend?

  • A. Use Observability in Foundry Control Plane with evaluation and drift monitoring.
  • B. Enable Application Insights and use Azure Monitor.
  • C. Deploy each new agent version directly to production.
  • D. Configure GitHub Actions for new agent versions.

✅ Đáp án chính thức: A — Use Observability in Foundry Control Plane with evaluation and drift monitoring.

Vì sao đúng: Observability in Foundry Control Plane kết hợp với evaluation cho phép đánh giá agent theo baseline metric trước khi deploy.Drift monitoring tiếp tục theo dõi sau triển khai để phát hiện khi chất lượng phản hồi thay đổi hoặc suy giảm theo thời gian. Đây là đúng nhu cầu kiểm soát chất lượng vòng đời agent.

Vì sao đáp án khác sai: A. GitHub Actions: Hữu ích để tự động hóa build/test/deploy trong CI/CD, nhưng không phải công cụ chuyên đánh giá chất lượng agent và theo dõi drift.B. Deploy trực tiếp mọi version lên production: Rủi ro vì không có bước đánh giá theo baseline trước khi đưa version mới vào production.D. Application Insights và Azure Monitor: Chủ yếu theo dõi runtime, telemetry, lỗi, độ trễ và tài nguyên. Không trực tiếp cung cấp đánh giá agent theo baseline cùng drift monitoring chuyên biệt.

🪄 Câu thần chú: Đánh giá trước deploy + phát hiện chất lượng trôi dạt sau deploy → Observability + evaluation + drift monitoring.

Vì sao đáp án khác sai: A. Track average user-session duration: Đo mức độ sử dụng/engagement, không trực tiếp giúp prompt rõ hơn hoặc phản hồi chính xác hơn.B. Analyze prompt-length distribution: Có thể là số liệu tham khảo, nhưng độ dài prompt không tự cho biết prompt có rõ ràng, chính xác hay hiệu quả không.E. Measure system resource usage: Đo hiệu năng hạ tầng như CPU/memory, không phải kỹ thuật cải thiện nội dung và chỉ dẫn của prompt.

🪄 Câu thần chú: Prompt tốt = viết rõ, test đều, sửa theo phản hồi người dùng.

Câu 66

You need to recommend a security solution for agents in a Microsoft Power Platform environment.The agents must use only approved connectors and services. The solution must prevent the agents from accessing sensitive data.What should you recommend?

  • A. Configure Azure Monitor to capture connector activity logs.
  • B. Enable customer-managed keys in Microsoft Dataverse.
  • C. Enable a Microsoft Dataverse audit.
  • D. Deploy data loss prevention (DLP) policies in Power Platform.

✅ Đáp án chính thức: D — Deploy data loss prevention (DLP) policies in Power Platform.

Vì sao đúng: Power Platform DLP policies cho phép quản trị viên phân loại, cho phép hoặc chặn connector. Nhờ đó, agent chỉ truy cập các dịch vụ được phê duyệt và không thể kết hợp/truyền dữ liệu nhạy cảm qua connector không được phép.

Vì sao đáp án khác sai: A. Azure Monitor connector activity logs: Chỉ ghi nhận/quan sát hoạt động sau hoặc trong khi xảy ra; không ngăn agent dùng connector không được phép.B. Microsoft Dataverse audit: Audit lưu lịch sử thay đổi và truy cập dữ liệu Dataverse, nhưng không kiểm soát chính sách sử dụng connector của agent.D. Customer-managed keys in Dataverse: Bảo vệ dữ liệu bằng encryption at rest với khóa do khách hàng quản lý, nhưng không quyết định connector nào được agent sử dụng.

🪄 Câu thần chú: Chặn connector không an toàn trước khi lộ dữ liệu → Power Platform DLP policies.

Câu 67

A company has a Microsoft Foundry agent that summarizes customer feedback and recommends products to customers. The agent references data from multiple knowledge sources.Users report that the agent response time is slow.Telemetry data shows that the agent frequently reaches its token usage limit.You need to recommend a solution to reduce token usage without degrading the quality of the generated responses.What should you recommend?

  • A. Reduce the number of knowledge sources used by the agent.
  • B. Reconfigure the prompts to limit the amount of retrieved content from the knowledge sources.
  • C. Chunk documents during indexing.
  • D. Lower the maximum token usage limit for the responses.

✅ Đáp án chính thức: B — Reconfigure the prompts to limit the amount of retrieved content from the knowledge sources.

Vì sao đúng: Cấu hình prompt để giới hạn lượng nội dung được truy xuất sẽ giảm input token, nên agent xử lý nhanh hơn. Đồng thời vẫn giữ các knowledge source hiện có, chỉ lấy phần liên quan và cần thiết hơn.

Vì sao đáp án khác sai: A. Chunk documents during indexing: Chunking có thể giúp retrieval chính xác hơn, nhưng không trực tiếp giới hạn tổng lượng context được đưa vào prompt.B. Reduce the number of knowledge sources: Có thể giảm token, nhưng dễ làm thiếu thông tin và giảm chất lượng/căn cứ của câu trả lời.D. Lower maximum token usage for responses: Chủ yếu giới hạn output token của câu trả lời, không giải quyết nguyên nhân là quá nhiều input context được truy xuất; còn có thể làm câu trả lời bị cụt.

🪄 Câu thần chú: Phản hồi chậm vì context quá nhiều → giới hạn retrieved content trong prompt, không cắt knowledge source.

Câu 71

Overview

Contoso, Ltd. is a high-tech manufacturing company that uses Microsoft Dynamics 365 Finance. Dynamics 365 Supply Chain Management, and Dynamics 365 Commerce for its North American operations. The company designs and develops innovative products that have many patents and proprietary technologies. The patents and engineering designs are closely guarded secrets. Contoso executives want to integrate and adopt AI solutions to help scale the company in preparation for an anticipated period of rapid growth. The company has multiple legal entities and Azure subscriptions that will be used in the adopted AI solutions.

AI Adoption

The following executives will have specific responsibilities in the overall AI adoption:

  • Chief Technology Officer (CTO): Select one Dynamics 365 Finance, Dynamics 365 Supply Chain Management or Dynamics 365 Commerce prebuilt AI agent and one custom Microsoft Copilot Studio AI agent to prioritize and deploy during the initial AI adoption phase.
  • Chief Information Officer (CIO): Ensure that appropriate security labels are assigned to the data used by the AI agents.
  • Chief Financial Officer (CFO): Analyze the return on investment (ROI) for the AI agents being deployed.
  • Chief Information Security Officer (CISO): Discover and inventory AI resources for auditing.
  • Chief Executive Officer (CEO): Ensure that all solutions adhere to industry-standard responsible AI practices.

All AI initiatives and agents will have a detailed business use case, a defined audience profile, and an estimated ROI that will compare the cost savings of the current process against the estimated costs of using the new AI solutions. The company’s research and development (R&D) department already has a custom Model Context Protocol (MCP) server that contains comprehensive product specifications and compliance data.

Prebuilt AI Agent

The CTO has NOT yet selected which prebuilt AI agent to use in Dynamics 365 Supply Chain Management. The CTO wants to view available agent templates to identify which agent will add the most business value.

Depending on which high-priority AI agents are identified, its agent capabilities must be previewed in a discovery meeting with the relevant business operation stakeholders.

Custom AI Agent

Contoso has identified the following custom AI agent requirements:

  • The custom AI agent will use data from Dynamics 365 Supply Chain Management to answer questions for the manufacturing team as a low-code solution.
  • The custom AI agent will be accessible from within Microsoft Teams.
  • The custom AI agent must be designed to eventually connect to other agents that can be selected based on their description.
  • The topics used in the custom AI agent will be selected based NOT on a trigger phrase, but on a description of the purpose of the query, to make the interactions more conversational.
  • The custom AI agent must be able to answer questions about product specifications by using existing technologies. The product specifications are maintained by the R&D department.
  • The custom AI agent must be integrated with and accessible from Dynamics 365 Supply Chain Management.
  • The custom AI agent must be able to use Dynamics 365 Supply Chain Management business logic that is stored outside of the application.

Analysis, Reporting, and Troubleshooting

Contoso has identified the following analysis, reporting, and troubleshooting requirements:

  • The CISO will audit all the AI solutions monthly for compliance and security.
  • The CFO will analyze all the AI solutions quarterly to compare the estimated ROI against actual measured efficiencies and adoption. The CFO will use the Copilot Studio agent usage estimator to perform this analysis.
  • The CISO wants to identify how much sensitive data was accessed for a given AI agent run and who accessed the data. Too much sensitive data accessed by a single user might indicate a high security risk.
  • The CTO wants to track user feedback on the quality of the AI agent responses during user interactions with the agents. Consistently poor feedback will trigger an escalated reengineering discussion.
  • The CEO wants a quarterly assessment of all the required metrics for their specific responsibilities. The tools used for the assessments must be Microsoft-recommended and must verify reliability, interpretability, fairness, and compliance.
  • The CFO wants to identify how many interactions with the AI agents are abandoned on a given day as compared to resolved conversations. Too many abandoned sessions might indicate that Copilot Studio credits are being used inefficiently by end users.

What should you recommend to assist the CEO with their specific responsibilities?

  • A. The Microsoft Service Trust Portal
  • B. Microsoft Foundry Tools
  • C. Compliance Center
  • D. Microsoft Purview
