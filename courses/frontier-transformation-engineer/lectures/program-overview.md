# Tổng quan chương trình & lộ trình 3 milestone

> Ghi chú khởi động: chương trình này gồm những gì, thứ tự nên học, và các mốc bắt buộc để lấy badge. Các phần chi tiết từng khoá sẽ tách thành topic riêng (L02, L03, …).
>
> **Nội dung chương trình cập nhật đến tháng 9/2026** — số khoá, thời lượng và yêu cầu milestone có thể thay đổi sau mốc này; kiểm tra lại trang chương trình khi học.

## 1. Chương trình là gì

- Tên: **Frontier Transformation Engineer** (Microsoft — Skill Up with Level Up).
- Mục tiêu: trang bị năng lực AI để biến tổ chức thành **Frontier Firm** — doanh nghiệp vận hành với con người + AI agent làm việc song song.
- Quy mô: ~**86 giờ**, **11 khoá**, học tự do theo nhịp cá nhân.
- Đầu ra: **Frontier Transformation Engineer Badge** sau khi hoàn thành 3 milestone.
- Đối tượng: Solution Engineer, AI Engineer, Cloud Engineer, Solution Architect, Technical Consultant.

## 3. Công nghệ chính sẽ gặp

- **GitHub Copilot** — lập trình hỗ trợ AI.
- **Azure AI / AI Foundry** — build AI apps và agent.
- **Microsoft IQ / Work IQ** — lớp "trí tuệ tổ chức" trên dữ liệu Microsoft 365.
- **Agentic AI** — thiết kế, điều phối multi-agent.
- **Microsoft Fabric IQ & Data Agents** — agent truy vấn dữ liệu doanh nghiệp.
- **Agent 365** — quan sát (observe), quản trị (govern), bảo mật (secure) agent ở quy mô tổ chức.

## 4. Thứ tự học đề xuất (nháp)

1. GH-300 (Copilot) — nhẹ, làm quen trước.
2. Microsoft IQ (1h) — khái niệm nền cho các khoá sau.
3. AI-102/AI-103 — nền tảng Azure AI.
4. Accelerate Agentic AI + AB-100 — phần agentic, học gần nhau cho liền mạch.
5. Fabric IQ & Data Agents.
6. Agent 365 — governance, học sau khi đã hiểu agent.
7. Hypervelocity Engineering Framework — chốt Milestone 3.

## 5. Câu hỏi cần trả lời khi học xong

- "Frontier Firm" khác doanh nghiệp dùng AI thông thường ở điểm nào?
- Khi nào dùng Copilot extension vs. custom agent vs. multi-agent orchestration?
- Work IQ lấy ngữ cảnh từ đâu, ranh giới bảo mật/permission ra sao?
- Agent 365 giải quyết vấn đề gì mà nền tảng agent cơ bản không lo được?
- Hypervelocity Engineering Framework gồm những vòng lặp / vai trò nào?
